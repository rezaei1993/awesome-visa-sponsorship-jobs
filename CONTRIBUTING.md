# Contributing

Thanks for helping improve this list.

## Guidelines

1. Prefer **actively maintained** resources with working links.
2. Keep descriptions **short and objective** (no vague marketing).
3. Put new job boards in the most relevant section.
4. One suggestion per pull request when possible.
5. Do not add duplicates.
6. Company lists should point to careers pages or well-known community databases — not single expired job posts.

## Format

```md
- [Name](https://example.com/) — Short objective description.
```

Or numbered entries when the section is ranked / ordered.

## Process

1. Fork the repository
2. Create a branch
3. Edit `README.md`
4. Open a pull request explaining why the resource belongs here
